# Example 02

This example expands the DevOps core with:

- mirrored GitHub repository
- Docker deploy artifact
- OKE deploy environment
- repository trigger that launches an existing build pipeline

This example is intended to be paired with **`terraform-oci-fk-devops-pipeline`**, which creates the referenced build pipeline.

## Usage

```bash
tofu init
tofu plan
```
