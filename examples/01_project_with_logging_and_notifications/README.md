# Example 01

This example creates a minimal **OCI DevOps project** with:

- notification topic
- service logging

It is the simplest starting point before you add repositories, artifacts, deploy environments, or triggers.

## Files

- `main.tf`: module call
- `provider.tf`: OCI provider configuration
- `variables.tf`: example inputs
- `outputs.tf`: useful outputs

## Usage

```bash
tofu init
tofu plan
```
